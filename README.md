# PantryPilot（食刻管家） 工程交付包

版本：1.0.0；基线日期：2026-11-14；团队：3 名开发人员。

## 内容

- 文档：立项、需求、原型说明、总体设计、数据库/API、AI 设计、测试、部署、验收总结模板。
- 产品原型：可点击低保真 HTML。
- 架构图：draw.io 多页可编辑文件。
- 工程管理台账：Backlog、Sprint、RTM、风险、缺陷、ADR、测试用例。

## 使用约束

这些材料是项目启动阶段的工程基线和模板，不代表已完成访谈、开发、测试、部署或验收。实际记录必须据实补充。数据库采用 PostgreSQL，不使用 SQLite。AI 输出须经过 Schema 和业务规则校验；录入和库存扣减均须用户确认。原型使用静态示例数据，不连接真实 AI/数据库。

## 使用顺序

先评审 01/02，再评审 03 与 HTML 原型，然后冻结 04/05/06 的架构、数据、接口和 AI 契约；执行时使用 Excel 台账追踪；按 07 测试、08 部署、09 验收。
